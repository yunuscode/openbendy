# OpenBendy icon

Original vector artwork for openbendy.com: a folded lowercase b with an open counter.

- `openbendy.svg`: transparent color mark, 512 × 512 viewBox.
- `openbendy-mono.svg`: transparent single-color mark using currentColor.
- `openbendy-app-icon.svg`: native app-icon composition, 1024 × 1024 viewBox.
- `openbendy-app-icon.png`: 512-pixel raster preview.

All SVGs are editable paths and contain no embedded bitmaps, fonts, scripts, or external dependencies.
